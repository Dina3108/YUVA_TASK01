YUVAINTERN — VIRTUAL DATA SCIENCE WITH PYTHON APPRENTICE INTERN
Package contents:
- code/week1_task.py through code/week5_task.py: one Python script per weekly task
- reports/week1_report.docx through reports/week5_report.docx: Word reports with methodology, results, visualizations, limitations, and report descriptions
- week1_report_description.txt through week5_report_description.txt: separate descriptions for the YuvaIntern submission field (each meets the portal's stated 200-word minimum)
- diabetes_dataset.csv: a copy of the built-in teaching dataset for reference
- plots/: generated visualizations used in the reports

Dataset note:
The code loads scikit-learn's built-in diabetes dataset locally; no web download or API key is required.
Install dependencies:
pip install pandas numpy matplotlib seaborn scipy scikit-learn python-docx
Run each script from the package root, for example:
python code/week1_task.py

Important:
These are reproducible educational examples. Review and rerun each script before submission, confirm the report outputs match your environment, and replace or add your own work if your internship requires original analysis. The diabetes dataset is not a clinical decision tool.

Code style update: The five Python scripts have been rewritten with simpler variable names, short explanations, and comments that describe the reason for each step. Please run and review them before submitting.
